# Mysuru Homes — frontend

React 19 + Vite, plain JavaScript and plain CSS (no TypeScript, no Tailwind).

See the [repo root README](../README.md) for setup, environment variables,
demo accounts, architecture and how to run the tests.

```
npm install
npm run dev      # http://localhost:5173, proxies /api and /uploads to :8080
npm test         # Vitest — formatRent, IST time helpers, etc.
npm run lint     # oxlint
npm run build    # production build to dist/
```
